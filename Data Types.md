# Declaring Variables in Different Data Types  ✏️

## Integer 1️⃣
DATA int TYPE i. 

## Decimals 1️⃣.0️⃣
DATA dec TYPE p DECIMALS 2.
DATA dec TYPE p LENGTH 2 DECIMALS 2.

## Character 🅰️
DATA ch TYPE C LENGTH 10.

## String 🔤
DATA str TYPE string.
