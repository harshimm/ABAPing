# Variables 🗘 
Value can be changed anytime in the program.

### Example :
```
WRITE 'CONSTANTS AND VARIABLES'.

DATA variable TYPE i.

variable = 1.
WRITE / variable.

variable = 2.
WRITE / variable.
```
### Output
```
2
```

# Constants 🛑
Value cannot be changed in the program.

### Example :
```
CONSTANTS constant VALUE 1.
WRITE / constant.

constant = 2.
WRITE / constant.
```

### Runtime error
```
The field "CONSTANT" cannot be modified.
```
