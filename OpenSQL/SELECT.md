# SELECT Statement 👆

### Select all fields
```
DATA IT_ZLEAVEREQ TYPE ZLEAVEREQ.

SELECT * FROM ZLEAVEREQ INTO IT_ZLEAVEREQ.

WRITE: / IT_ZLEAVEREQ-CLIENT,
IT_ZLEAVEREQ-REQUESTID,
IT_ZLEAVEREQ-TALENTID,
IT_ZLEAVEREQ-FROMDATE,
IT_ZLEAVEREQ-TODATE,
IT_ZLEAVEREQ-REQTYPE,
IT_ZLEAVEREQ-CREATEDON,
IT_ZLEAVEREQ-ZZFIRSTNAME,
IT_ZLEAVEREQ-ZZSURNAME,
IT_ZLEAVEREQ-CREATEDAT,
IT_ZLEAVEREQ-ZZMFIRSTNAME,
IT_ZLEAVEREQ-ZZMSURNAME.

ENDSELECT.
```

### Select particular field(s) only
```
SELECT FROM ZLEAVEREQ FIELDS
TALENTID,
FROMDATE,
TODATE,
REQTYPE,
CREATEDON,
ZZFIRSTNAME,
ZZSURNAME,
CREATEDAT

INTO CORRESPONDING FIELDS OF @WA_ZLEAVEREQ.

WRITE: / WA_ZLEAVEREQ-TALENTID,
WA_ZLEAVEREQ-FROMDATE,
WA_ZLEAVEREQ-TODATE,
WA_ZLEAVEREQ-REQTYPE,
WA_ZLEAVEREQ-CREATEDON,
WA_ZLEAVEREQ-ZZFIRSTNAME,
WA_ZLEAVEREQ-ZZSURNAME,
WA_ZLEAVEREQ-CREATEDAT.

ENDSELECT.
ULINE.
SKIP 2.
```
