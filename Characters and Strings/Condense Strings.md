# Condense Strings 🥶
- Used to remove extra spaces in s string.
- By default, it returns string with a single gap between each word.

```
  result = 'Harshini   is a    smart   girl'.
```

### 1. Condense string with single gap between each word
```
CONDENSE result.
WRITE / result.
```
### Output
```
Harshini is a smart girl
```

### 2. Condense string without gap between each word
```
CONDENSE result NO-GAPS.
WRITE / result.
```
### Output
```
Harshiniisasmartgirl
```
